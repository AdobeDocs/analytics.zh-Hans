# Web SDK迁移规划者

Web SDK迁移规划者可帮助您计划并执行Adobe Analytics标记扩展到Adobe Experience Platform Web SDK的迁移。 它将迁移引入Adobe Experience Platform数据收集中的单个引导式工作区，因此您可以采用结构化、可跟踪的方式，从现有标记实施移至Web SDK。

>[!AVAILABILITY]
>
>工具和文档均处于积极开发状态。 文档发布时间定于2026年9月下旬。
